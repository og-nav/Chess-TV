# App sound sets

Settings offers six sets: Recorded Wood, Muted Wood, Soft Felt, Lichess Piano,
Lichess NES and Lichess SFX. Each has move, capture and check clips; all share the
existing original game-over chime. Recorded Wood is the default. Muting sounds
does not discard the selected set. Explicit previews remain available while muted.

`python3 scripts/make-sounds.py` regenerates all assets (requires ffmpeg), the
comparison gallery, and the bundled Lichess license notices. The app's 18 set
clips exactly match the level-matched gallery. Their flat resource filenames are
`sound-{wood,muted,felt,piano,nes,sfx}-{move,capture,check}.wav`.

- **Recorded Wood / Muted Wood:** el_boss, CC0. See [sources](wooden-chess/README.md).
  Muted Wood is pitched down and low-pass filtered.
- **Soft Felt:** original synthesis, generated by `scripts/make-sound-auditions.py`.
- **Lichess Piano / NES / SFX:** Enigmahack and the Lichess authors, AGPLv3 or later.
  The original MP3s, full license, copying notice and pinned URLs/checksums are in
  [the source directory](../../design/audio-auditions/sources/lichess/manifest.json).
  Chess TV's modifications are mono WAV conversion, resampling and level matching.
  The license and copying notice are bundled in both apps; Credits includes attribution.

Audio playback and hardware preparation run off the main actor. Only requested
sets load, and a preference change applies to the next live move. Previews use
separate players, cancel when replaced, and stop when leaving Settings or entering
the background. The saved preference is local to each device.
